# Project rules

- At the start of every new session/agent working in this repo, read
  `memory.txt` in the project root first. It contains the project brief
  (what we're building and why) and a session log of prior progress —
  read it before making any changes so you know where things stand.
- Before ending a session (or handing off), append a new dated entry to
  the SESSION LOG section of `memory.txt` summarizing what changed and
  what's next. Keep entries short (a few sentences), newest at the
  bottom. Update the CURRENT STATE section if it's gone stale.
